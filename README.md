# CORTE FINO
CorteFino es un sistema de citas para barberías y salones que permite a los clientes agendar servicios con un barbero sin cruces de horario y acumular puntos de fidelidad, y a los barberos y al dueño gestionar la agenda y el catálogo.

## Cómo ejecutar el proyecto
1. Clonar el repositorio con git clone y la URL del repo.
2. Abrir la carpeta en VS Code.
3. Abrir index.html en el navegador.
## Flujo de trabajo
